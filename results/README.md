# Results

Result tables (CSV), figures (PNG) and `MANIFEST.json` saved by the notebook
(`notebook/GridDefense_Final.ipynb`). `MANIFEST.json` lists the MD5 fingerprint of every saved file
and the library versions, so any file here can be checked against the notebook run.

Results produced by the package scripts (`scripts/evaluate.py`) go to `results/package_run/`, which is
not committed.
